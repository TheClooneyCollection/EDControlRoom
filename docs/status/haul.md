## Caveats
- Orbital station automation now treats pad-full `DockingDenied` reasons like `NoSpace` as transient hold-and-retry cases; other denial reasons still use the generic short retry path until live journals justify stricter classification, and since 2026-11-11 a haul restarted after the retries run out sends a fresh dock request (a `DockingDenied`/`DockingTimeout`/`DockingCancelled` for the destination resumes as near-station, not as a pending request), and `on land` stations are landed manually: two-way and multi-leg haul TTS `manual_landing` after the drop, wait for `Docked` (dock timeout) and then trade and continue; before 2026-11-10 haul exited there, so the run was recorded aborted and `resume` found no haul. Standalone `travel`/Spansh routes still end at the handoff.
- One-sided loops (station-side UI timing, resume with no station buy) and multi-leg flow still need live validation; multi-leg for repeated stations, consecutive trades, final-leg completion semantics, and external routes that set `manual_landing`; the new local-observer Inara search path still needs live operator validation for route-to-haul handoff in `connect` mode.
